# Employee Attrition Prediction

## Description
He ek web application aahe jyamadhe employee company sodel ki nahi (attrition) hyacha andaj Machine Learning model vaparun lavla jato. User employee chi mahiti bharto aani app result dakhavto.

## Technologies Used
- Python
- Flask
- Machine Learning (scikit-learn, pandas, numpy)
- HTML, CSS

## Features
- Employee chi mahiti form madhe bharne
- Attrition cha prediction (Yes / No) baghne
- Simple aani easy web interface

## How to Run
1. Repository clone kara:
   git clone https://github.com/poojasuryawnshi2411/Employee-Attrition-Project1.git
2. Project folder madhe jaa:
   cd Employee-Attrition-Project1
3. Required libraries install kara:
   pip install -r requirements.txt
4. App chalva:
   python app.py
5. Browser madhe ughda:
   http://127.0.0.1:5000
